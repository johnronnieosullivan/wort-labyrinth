# Wort-Labyrinth

Ein Deutsch-Lernspiel für die 4. Klasse Volksschule: Wortarten und Satzglieder.
Jede Tür im Labyrinth stellt eine Frage. Inspiriert von [jd-d/labyrinthus](https://github.com/jd-d/labyrinthus).

**Spielen:** https://johnronnieosullivan.github.io/wort-labyrinth/

Alles steckt in `index.html` – ohne Abhängigkeiten. Neue Sätze kommen in die Liste `SENTENCES`.
